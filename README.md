# Cube Coach

Cube Coach is a web-based tool made to help speedcubers train and improve their solves with timing, analysis and algorithm learning.

# Features

# Timer
- Timer that is controlled by the spacebar
- Similar to stackmat timer, hold to start
- Tracks solve history
- Average of 5 calculation
- Support for penalties (+2 and DNFs)

# Analysis
- Input scramble and your solution to the scramble
- Will breakdown each step (Cross, F2L, OLL and PLL)
- Finds shorter cross solutions and F2L solutions
- Can preview cube at any point of your solution with a 3D cube model

# Algorithms
- PLL set is completed
- OLL set has a few algs as proof of concept
- Expandable for other sets (ZBLL, COLL, etc)

# Authentication
- Can register and login
- Uses JWT based authentication
- All solves get saved per user
